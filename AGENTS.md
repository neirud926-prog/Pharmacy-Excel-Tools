# Pharmacy Excel Tools

Excel/VBA tools for the pharmacy. Each tool lives in its own folder (`BCS Tool`, `Return Drug`, `Short Expiry Log Book`, `Stocktake`) and holds its `.xlsm` workbook plus the exported VBA sources (`VBA/` or `vba/`). The exported `.bas`/`.frm`/`.cls` files are the reviewable source; re-import them into the workbook after changing them.
